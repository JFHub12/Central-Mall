# Central Mall

Central Mall is an interactive web application designed to help visitors explore a mall easily and enjoy a smooth, modern experience. The platform provides a simple way to browse different areas of the mall, discover stores and services, and get helpful support while navigating the space.

## About the Project

This project combines a clean user interface with useful features such as navigation, store discovery, location guidance, and an AI-powered chatbot. It is built to make the mall experience more convenient, informative, and engaging for users.

## Features

- Welcoming homepage with an attractive and modern design
- Interactive mall views for exploring different sections
- Information about shops, services, and important locations
- AI chatbot support for answering questions and assisting users
- Secure authentication pages for user access
- Dashboard view for easy navigation and overview
- GPS-related features to help users find locations more easily

## Who Can Use It

This website is ideal for mall visitors, shoppers, and anyone looking for a convenient way to explore a mall and find useful information quickly.

## Purpose

The main goal of Central Mall is to make visiting and exploring the mall easier, more accessible, and more enjoyable for everyone.
